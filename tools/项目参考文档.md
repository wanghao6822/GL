- **语言**: C++

### 关键库

- Modbus-Arduino / Modbus-Serial / Modbus-Ethernet
- ADS1X15 (模拟量采集)
- PCF8575 (I2C 扩展 IO，预留)
- STM32duino FreeRTOS

## 模拟量输入（ADS1115，I2C 地址 0x48，增益 ±4.096V）

### 信号链路

```
高压直流(HM/KM) → 电阻分压(降压) → EXAI端子 → R64/R66(10kΩ) ─┬─→ LM358 IN+ → OUT → ADS1115 ADC
                                                     R65/R67(22kΩ)
                                                       │
                                                      GND
```

### 运放前端分压电路

| 通道 | 输入电阻 | 对地电阻 | 分压比 | 逆系数 |
|:----:|:--------:|:--------:|:------:|:------:|
| AI0 | R64=10kΩ | R65=22kΩ | 22/32=0.6875 | **1.4545** |
| AI1 | R66=10kΩ | R67=22kΩ | 22/32=0.6875 | **1.4545** |

### 转换公式

```
V_ADC    = ADC_value × 4.096 / 32767        (ADS1115增益=1, ±4.096V)
V_EXAI   = V_ADC × 1.4545                    (运放前端分压逆算)
V_bus    = V_EXAI × 校准系数                  (高压侧分压逆算，默认91倍)
```

即：`V_bus = ADC_value × 4.096 / 32767 × 1.4545 × calibration`

> **LM358 运放**：接成电压跟随器（OUT 直连 IN-），8脚接5V供电，4脚GND。

| 名称 | ADS1115 通道 | Modbus 寄存器 | 用途 |
| ---- | ------------ | ------------- | ---- |
| AI0  | 通道 0       | 寄存器 15     | 合母电压（HM，默认91:1分压，可通过寄存器31校准） |
| AI1  | 通道 1       | 寄存器 16     | 控母电压（KM，默认91:1分压，可通过寄存器32校准） |
| AI2  | 通道 2       | 寄存器 17     | 预留 |
| AI3  | 通道 3       | 寄存器 18     | 预留 |

## 硅链调压控制原理

### 物理模型

```
+HM ──┬──→ 电阻分压 → AI0(ADC) → 寄存器15(原始值) → 寄存器20(HM实际电压×100)
      │
      ├──→ 硅链降压（3继电器×8档位）──→ +KM
      │         ↑
      │    Y2/Y3/Y4 继电器组
      │         ↑
      │    SetGearOutput(gear)
      │
      └──→ KM ──→ 电阻分压 → AI1(ADC) → 寄存器16(原始值) → 寄存器21(KM实际电压×100)
```

**核心概念**：控母电压 KM = 合母电压 HM − 硅链降压值。硅链调压的本质是通过切换继电器档位改变硅链降压值，使 KM 接近目标电压。

### 调压算法（等效 PLC 梯形图10 公式）

```
deviation  = TargetVoltage - KM              // 偏差（×100）
gear_steps = deviation / dynStepVoltage      // 需调整档位数
targetGear = clamp(CurrentGear ± gear_steps, 0, 7)  // 钳位到有效档位
```

| 场景 | deviation | 动作 | 效果 |
|------|:---------:|------|------|
| KM < 目标 | 正 | 升档(减小降压) | KM 升高趋近目标 |
| KM > 目标 | 负 | 降档(增大降压) | KM 降低趋近目标 |
| \|deviation\| ≤ 死区 | — | 不调整 | 稳态 |

### 档位-继电器-降压值对应表（与 SCTY-D1 用户手册表3一致）

| 档位 | Y2 | Y3 | Y4 | 降压值(220V) | 降压值(110V) |
|:----:|:--:|:--:|:--:|:------------:|:------------:|
| G0 | 0 | 0 | 0 | 35V | 21V |
| G1 | 1 | 0 | 0 | 30V | 18V |
| G2 | 0 | 1 | 0 | 25V | 15V |
| G3 | 1 | 1 | 0 | 20V | 12V |
| G4 | 0 | 0 | 1 | 15V | 9V |
| G5 | 1 | 0 | 1 | 10V | 6V |
| G6 | 0 | 1 | 1 | 5V | 3V |
| G7 | 1 | 1 | 1 | 0V(直通) | 0V(直通) |

> 1=继电器导通/闭合(LOW)，0=继电器断开(HIGH)

### 控制模式（寄存器28）

| 值 | 含义 | 说明 |
|:--:|------|------|
| 0 | 强制自动 | 固件控制硅链，忽略X0 |
| 1 | 强制手动 | 上位机控Y2-Y5，忽略X0 |
| 2 | 跟随X0（默认） | X0=闭合→自动，X0=断开→手动 |

> **优先级**：寄存器28 > X0硬件开关。寄存器28=2时由外部硅链转换开关(X0)决定。

### 动态压差学习

- 由于硅堆制造差异，每档实际降压值并非精确等于默认值 3.50V
- 固件在每次调档后等待 1 秒，对比调前/调后 KM 电压差，计算 **实际每档压降**
- 公式：`dynStepVoltage = (KM_before - KM_after) / gear_delta`
- 动态死区 = 动态每档压差（自适应）
